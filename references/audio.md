# Narration without tying the skill to a provider

The exporter consumes `assets/narration.wav`; it doesn't need a Gemini account or any online speech service. A human recording or audio generated by another tool works through the same import command. The included focus example has a ready-to-use narrated recording, so the complete pipeline can be tried without spending credits or supplying a key.

## Import a recording

First measure/listen to the recording and set the beat and caption timing in `content.json`. Then:

```sh
node scripts/prepare-audio.mjs /path/to/project /path/to/recording.mp3
```

FFmpeg accepts supported recording formats, normalizes to a -16 LUFS loudness target and -1.5 dB true-peak target, converts to mono 48 kHz WAV, and pads the closing hold. It refuses to cut a recording that is longer than the video or overwrite existing narration. Normalization is one-pass; inspect the final sound and measurements when precise loudness compliance matters. No automatic timing or transcription service is hidden in this command.

## Optional Gemini adapter

`scripts/gemini-tts.py` uses Python's standard library. It reads the actual transcript unchanged and requests a single speaker. It does not silently replace Latin words with Arabic or rewrite the approved script. Make a separate, reviewed `speech-input.txt` if pronunciation spellings differ from the readable script.

```sh
python3 scripts/gemini-tts.py /path/to/speech-input.txt /path/to/voice.wav
```

It asks privately for a key if `GEMINI_API_KEY` isn't already present in the environment. Use your agent's secure secret mechanism when available; don't paste a key into a tracked file or a recorded shell command. Voice and model can be selected with `--voice` and `--model`. Defaults are Charon and `gemini-3.8-flash-tts`. The adapter makes one request, fails visibly on errors, and doesn't automatically retry/bill again. The small accompanying metadata file records model/voice/usage, not the key or the service response id.

The request follows Google's [speech-generation REST documentation](https://aistudio.google.com/docs/speech-generation), checked 2026-11-17. Provider availability, pricing and models can change; verify before changing models. The original Quran example was actually generated with Gemini 3.8/Charon. Packaging tests mock the API and do not make another paid request.

## Review and future local speech

Check names, pace, sentence endings and every non-English quotation. Automatic speech recognition can help find omissions but can itself mishear correct audio. Human review remains valuable, especially for Quran recitation. Do not describe ordinary generated Arabic speech as a certified recitation.

Kokoro integration is deliberately deferred in this version. It should later produce the same recording input, without changing drawing/export code. Don't claim it is installed, supported for Arabic, or ready until the actual chosen version, language and voice have been tested. For now, supplied audio is the key-free path.
