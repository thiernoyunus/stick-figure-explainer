# Adraka and Yudrika — physical-action remake

Same approved script and Gemini 3.8/Charon narration as `../adraka-yudrika/`; eleven different physical-action scenes with modern reading partners.

From the repository root:

```sh
node scripts/render.mjs examples/adraka-yudrika-remake
node scripts/preview.mjs examples/adraka-yudrika-remake
```

See `SOURCES.md`, `script.txt`, `content.json`, `scenes.js`, and the native motion sheets under `output/native/`. Final frame/contact checks are in `output/verification.json`; script/audio preservation checks are in `output/preservation-check.json`. Existing voiceover is included; trying or re-exporting this example requires no API key.
